<objective>
Define the single response contract for the SharePoint backend: an immutable no-store header set, a closed set of error codes, and helpers that make it impossible to leak an exception message or a cacheable success body.

Purpose: SEC-05 requires that no token, secret, or internal detail crosses into the browser and that responses are never cached by an intermediary. Research showed the neighboring `apis/reporting-functions/index.js` returns `error.message` in a 500 — that is the exact anti-pattern this plan replaces before any endpoint exists, so 13-07 has no opportunity to reproduce it.
Output: `responses.py` with `PRIVATE_NO_STORE_HEADERS`, `ErrorKind`, `ERROR_MESSAGES`, `ApiError`, `private_json`, `private_error`, `to_https_response`, plus a header and sanitation test suite.

Decisions made in-plan:
- The module is named `responses.py` because `http.py` would shadow the standard-library `http` package inside the Gen2 source root, breaking `firebase-admin` imports.
- Error bodies use a two-field shape `{"error": {"code": <ErrorKind>, "message": <fixed string>}}`; there is no `details`, `debug`, or `cause` field in Phase 13.
- `to_https_response` is a thin adapter over the `firebase_functions.https` `Response` construction path used in 13-07; the pure-Python helpers stay testable without importing Firebase.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend exception → browser | Internal exception text and infra details must not cross this boundary. |
| Backend → intermediary cache / browser cache | Responses carry tenant data and must never be stored by a proxy or disk cache. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-08 | Information Disclosure | `private_error`, `ApiError.to_body` | high | mitigate | Closed `ErrorKind` enum plus fixed `ERROR_MESSAGES`; no free-form message parameter; tests assert sentinel absence including chained causes. |
| T-13-09 | Information Disclosure | response headers | high | mitigate | `PRIVATE_NO_STORE_HEADERS` as `MappingProxyType` applied to every status; override attempts raise `ValueError`; test sweeps nine statuses. |
| T-13-10 | Tampering | shared header constant | medium | mitigate | Immutable mapping and per-response copy; mutation test proves the constant cannot be poisoned by one handler. |
| T-13-11 | Denial of Service | error verbosity | low | accept | Fixed-length messages reveal nothing worth probing; no rate limit needed at this layer because 13-06 owns request rate limiting. |
</threat_model>
