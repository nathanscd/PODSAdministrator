<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `sharepoint_oauth_start` | Firebase Bearer required; response contains only an external HTTPS URL. |
| Microsoft → `sharepoint_oauth_callback` | Public `form_post` protocol exception; `state` is the only correlation key. |
| Transaction → Firestore | Single-use, Firebase UID/companyId-bound, expiring record. |
| Backend → Microsoft identity platform | MSAL validates code, PKCE, nonce and ID-token claims server-side. |
| Backend → Firestore token envelope | AES-256-GCM with canonical purpose; cache never crosses to browser. |
| Callback → Browser | Fixed `/settings` redirect without credential material. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-13 | Spoofing | `sharepoint_oauth_start` | critical | mitigate | `_authenticated` supplies UID/companyId; no identity from request body. |
| T-14-14 | Tampering | `state`/`nonce`/PKCE | critical | mitigate | SHA-256 persistence, atomic consume, MSAL flow validation and expiry. |
| T-14-15 | Elevation of Privilege | Microsoft `tid` | critical | mitigate | Validate against backend `ms_allowed_tenant_ids`; Firebase `companyId` remains authoritative. |
| T-14-16 | Information Disclosure | Callback redirect | high | mitigate | Fixed local `Location: /settings`, no query/fragment, error responses use `private_error`. |
| T-14-17 | Tampering | Token cache | critical | mitigate | `encrypt_blob` with `msal-cache-v1`, keyVersion from config, no filesystem/browser storage. |
| T-14-18 | Repudiation | Security logs | medium | mitigate | Allow-listed fields only; no code/state/nonce/token/claims/ciphertext. |
| T-14-SC | Tampering | `msal` runtime | high | mitigate | Import permitted only after 14-02 human approval and 14-03 pinned install. |
</threat_model>
