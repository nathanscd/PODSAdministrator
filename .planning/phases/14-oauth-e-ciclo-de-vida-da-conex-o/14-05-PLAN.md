<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → status/disconnect/start handlers | Firebase Bearer and private responses; no Microsoft material crosses to browser. |
| Backend → Microsoft Graph | Best-effort revoke with timeout, before local credential deletion. |
| Backend → Firestore | Token envelope deleted; connection record marks disconnected; business documents untouched. |
| Backend → Frontend | Enum status and neutral reason only; unknown values rendered neutrally. |
| Human review → `/settings` UI | End-of-phase human-check validates visible states and absence of browser storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-19 | Spoofing | `sharepoint_disconnect` | critical | mitigate | `_authenticated`; identity comes from verified Firebase token, never body input. |
| T-14-20 | Information Disclosure | Status payload | high | mitigate | Only enum, account email, persisted timestamp and generic reconnect reason; no error strings. |
| T-14-21 | Tampering | `sharepointApi.ts` | high | mitigate | HTTPS-only authorization URL, no query parsing, no browser persistence of sensitive values. |
| T-14-22 | Denial of Service | Revoke call | medium | mitigate | Best-effort with timeout; Graph failure never blocks local disconnect. |
| T-14-23 | Repudiation | `IntegrationsSection.tsx` | low | mitigate | Visible status from backend, neutral fallback, human-check records expected UI states. |
| T-14-SC | Tampering | `msal` runtime | high | mitigate | Already gated in 14-02/14-03; no new package or import in this plan. |
</threat_model>
