## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Cloud Function | Bearer Firebase ID token; status JSON privado com `no-store`. |
| Browser → Firestore | Regras default-deny para coleções SharePoint; nenhuma leitura cliente de credenciais. |
| Cloud Function → Firestore | Admin SDK lê `sharepointSettings` por `companyId` verificado. |
| Frontend → User | Badge e identidade vêm somente do backend; valores desconhecidos são neutros. |
